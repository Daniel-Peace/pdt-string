## Core Foundation
- strlen: Count characters until the null terminator (\0).
- strcpy: Copy a source string into a destination buffer.
- strcat: Append a source string to the end of a destination string.
- strcmp: Compare two strings lexicographically and return their difference.

## Safe Operations
- strncpy: Copy a set maximum number of bytes to prevent buffer overflows.
- strncat: Append up to a specific limit of characters safely.
- strncmp: Compare only the first n characters of two strings.

## Searching and Utilities
- strchr: Find the first occurrence of a specific character in a string.
- strrchr: Find the last occurrence of a character in a string.
- strstr: Locate a smaller substring inside a larger string.
- strdup: Allocate new memory and duplicate an existing string.
